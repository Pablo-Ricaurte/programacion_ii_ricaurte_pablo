## 🎯 Descripción del Curso

El objetivo de este curso es formar competencias en desarrollo de software moderno mediante el uso del lenguaje **Python** y sus frameworks más demandados en la industria:

1. **Python Avanzado:** Fundamentos sólidos, programación orientada a objetos (POO), manejo de estructuras de datos y módulos.
2. **Django Framework:** Desarrollo de aplicaciones web MVT (Modelo-Vista-Template), arquitectura ORM, autenticación, APIs y administración de bases de datos.
3. **Odoo ERP:** Arquitectura de módulos, personalización de vistas, modelos ORM de Odoo, flujos de trabajo empresariales y desarrollo de complementos (custom addons).

## ⚙️ Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/programacion_ii_ricaurte_pablo.git
   cd programacion_ii_ricaurte_pablo
   ```

2. **Crear y activar un entorno virtual de Python:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # En Linux/macOS o Codespaces
   # venv\Scripts\activate    # En Windows
   ```

3. **Instalar dependencias generales (si aplica):**
   ```bash
   pip install --upgrade pip
   # pip install -r requirements.txt
   ```
